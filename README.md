# 💳 ATM Machine Simulation (Console-Based Java Project)

## 📌 Project Overview
This is a console-based ATM Machine Simulation developed using Core Java.  
The application allows users to authenticate using a PIN and perform basic banking operations such as deposit, withdrawal, and balance inquiry.

This project demonstrates fundamental Java concepts including OOP, encapsulation, control flow, and input handling.

---

## 🚀 Features

- PIN Authentication
- Deposit Money
- Withdraw Money
- Balance Check
- Input Validation
- Menu-driven Console Interface

---

## 🛠️ Technologies Used

- Java (Core Java)
- OOP Concepts
- Java Scanner Class
- Array and Conditional Logic
